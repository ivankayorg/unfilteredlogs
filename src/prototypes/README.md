# UNFILTERED LOGS Front Page Prototypes

This folder is an isolated design sandbox for front-page experiments.

Production files outside this folder should not be changed while exploring concepts.
A prototype is only promoted into the live application after it is explicitly selected.

## Concepts

### 01-editorial-grid
Three featured posts across the top, followed by a dense feed and sidebar modules.

### 02-mid2000s-portal
A deliberately old-web content portal: compact modules, category strips, visible metadata, dense link/post discovery.

### 03-community-stream
A social/content hybrid centered on the live community feed with compact featured content and discussion activity.

### 04-magazine-board
A visual mixed-media board using cards of different sizes for YouTube, GIF, image, and text content while retaining ROFFLE interaction patterns.
